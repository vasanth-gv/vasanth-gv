## 🩺 AutoHeal — Self-Healing Application Deployment

> **CI/CD + Docker + AWS deployment with application health monitoring**

AutoHeal demonstrates a practical DevOps workflow where application code moves from GitHub through automated testing and containerized deployment.

### Pipeline

```text
Developer Push
      ↓
    GitHub
      ↓
   Jenkins
      ↓
   Jest Tests
      ↓
 Docker Build
      ↓
   AWS EC2
      ↓
 Application Health Check
      ↓
 Self-Healing / Restart
```

### Highlights

* GitHub webhook integration
* Jenkins CI/CD pipeline
* Automated application testing
* Docker containerization
* AWS EC2 deployment
* Docker health checks
* Container restart policy
* Application `/health` endpoint

**Stack:** `Node.js` `Express` `Jest` `Docker` `Jenkins` `AWS EC2` `GitHub`

🔗 **Repository:**
https://github.com/vasanth-gv/AutoHeal

## 🛡️ DriftGuard — Infrastructure Drift Detection

> **Terraform-based AWS security drift detection and CI security gate**

DriftGuard compares AWS infrastructure configuration against Terraform-managed infrastructure and identifies potentially risky security changes.

### Workflow

```text
Terraform Configuration
          ↓
      AWS Security Group
          ↓
     Drift Detection
          ↓
      Risk Analysis
          ↓
     Security Report
          ↓
      Jenkins Gate
```

### Highlights

* AWS Security Group monitoring
* Terraform state comparison
* Python + Boto3 automation
* Security risk reporting
* Jenkins security gate
* Infrastructure-as-Code workflow

**Stack:** `Python` `Boto3` `Terraform` `Jenkins` `AWS` `Security`

🔗 **Repository:**
https://github.com/vasanth-gv/DriftGuard
